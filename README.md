# The Investing School - Educational Stock Market Platform

Welcome to the official repository for **The Investing School** frontend website. This platform is designed to provide traders with institutional-grade knowledge, battle-tested strategies, and premium trading courses to achieve financial freedom.

## Features

- **Modern & Clean UI**: A professional light/white theme with responsive glassmorphism elements and depth effects.
- **Dual Phone Showcase**: Engaging 3D perspective hero section highlighting mobile app features.
- **Live Market Data**: Integrated with **TradingView** mini chart widgets for real-time tracking of assets like EUR/USD, AAPL, and SENSEX.
- **Dynamic Ticker Tape**: A scrolling marquee displaying live stock prices and indices.
- **Premium Courses Section**: Detailed layout showcasing various mentorship and trading programs.
- **Fully Responsive**: Optimized for both desktop and mobile devices.

## Tech Stack

- **HTML5**: Semantic structure and layout.
- **CSS3**: Custom styling, CSS Grid, Flexbox, and modern animations (No external CSS frameworks required).
- **Vanilla JavaScript**: DOM manipulation, interactive modals, and floating widgets.
- **TradingView Widgets**: Embedded financial charts and market data.
- **FontAwesome**: Icons for social media and UI elements.
- **Google Fonts**: Uses the 'Outfit' font family for a sleek, modern typography experience.

## Getting Started

To run this project locally, simply clone the repository and open the `index.html` file in any modern web browser. No complex build tools or servers are required.

```bash
git clone https://github.com/Lucky920487/Education_stock.git
```

## Disclaimer

This is an educational platform template. All stock market data and charts are provided by third-party widgets (TradingView) for demonstration purposes.
